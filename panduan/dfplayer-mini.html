01 / KENALI

Sebelum mulai.

DFPlayer mengurus pembacaan file audio dan keluaran speaker, sementara Arduino mengirim perintah lewat UART. Mulai dari satu file dan volume rendah. Setelah pemutaran stabil, barulah tambahkan tombol atau pilihan lagu.

Contoh catu
5 V teratur
Komunikasi
UART 9600
File uji
/mp3/0001.mp3
!
Perhatikan bagian ini

Produk di Excel menyebut JL 24. Varian chip dapat berbeda dari DFRobot asli: protokol, respons ACK, dan penamaan file perlu diuji pada unit. Kode berikut untuk unit yang kompatibel dengan protokol DFRobot, bukan jaminan semua clone.

04 / UJI

Coba satu langkah dulu.

  1. Pada microSD kosong yang sudah diformat, buat folder mp3 dan masukkan satu file bernama 0001.mp3. Lepas kartu dari komputer dengan aman.

  2. Dengan daya mati, masukkan kartu dan hubungkan speaker di antara SPK1 dan SPK2. Hubungkan serial dan resistor sesuai diagram.

  3. Pasang library, upload kode, lalu hidupkan catu modul. Buka Serial Monitor 9600 baud untuk melihat pesan inisialisasi.

  4. Jika unit kompatibel, satu file mulai diputar. Naikkan volume hanya setelah suara dan catu stabil. Jangan melepas kartu saat modul diberi daya.

Hasil yang diharapkan

File pertama diputar satu kali. Jika modul tidak memberi respons, kode berhenti dengan pesan yang bisa dibaca di Serial Monitor.

05 / KODE

Salin, upload, lalu amati.

Contoh ini mengikuti wiring di atas. Cocokkan board dan library sebelum menekan Upload.

Kode uji utama Arduino / C++
#include <SoftwareSerial.h>
#include <DFRobotDFPlayerMini.h>

SoftwareSerial audioSerial(10, 11); // RX, TX Arduino
DFRobotDFPlayerMini player;

void setup() {
  Serial.begin(9600);
  audioSerial.begin(9600);
  delay(1500);
  if (!player.begin(audioSerial)) {
    Serial.println("Modul tidak merespons. Periksa SD, UART, dan varian.");
    while (true) delay(100);
  }
  player.volume(10); // Rentang acuan DFRobot: 0-30.
  player.playMp3Folder(1); // /mp3/0001.mp3
}

void loop() {}

Cara membaca kodenya

  • Serial Monitor dan UART modul sama-sama 9600 baud, tetapi menggunakan jalur yang berbeda.
  • playMp3Folder(1) mengacu pada /mp3/0001.mp3 untuk protokol kompatibel.
  • Volume 10 adalah titik awal; kemampuan speaker dan supply tetap perlu diperhatikan.
06 / PERIKSA

Jika belum berhasil.

Mulai dari gejala yang paling dekat dengan hasil di meja.

Tidak ada suara+

Periksa nama folder/file, format SD, volume, speaker di SPK1/SPK2, dan catu.

Ada dengung atau suara putus+

Perpendek kabel, periksa ground dan catu, serta resistor seri pada RX modul.

Clone JL tidak lolos inisialisasi+

Cocokkan protokol dan ACK dengan dokumentasi unit. Jangan asal melewati pemeriksaan begin karena wiring yang salah juga dapat menimbulkan gejala sama.

07 / LANJUTKAN

Setelah uji pertama berhasil.

Tambahkan tombol setelah satu file berhasil diputar. Jangan menyambungkan SPK1/SPK2 ke input amplifier line-level; gunakan jalur DAC yang sesuai bila unit menyediakannya.
