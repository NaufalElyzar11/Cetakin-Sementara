01 / KENALI

Sebelum mulai.

Pastikan upload berhasil sebelum memasang sensor. Satu uji sederhana ini membantu membedakan masalah board dan kabel USB dari masalah rangkaian. Uno, Nano klasik ATmega328P, serta Mega memakai pilihan board yang berbeda walaupun kode uji berikut bisa digunakan pada ketiganya.

04 / UJI

Coba satu langkah dulu.

  1. Lepas semua rangkaian dari board. Pasang Arduino IDE dari situs Arduino dan hubungkan board dengan kabel USB data.

  2. Di pemilih board, gunakan Arduino Uno untuk Uno/R3, Arduino Nano untuk Nano klasik, atau Arduino Mega or Mega 2560 untuk Mega.

  3. Pilih port yang muncul setelah board dihubungkan. Jika CH340 belum terdeteksi, gunakan driver dari produsen WCH; hindari paket driver dari sumber yang tidak jelas.

  4. Upload kode, lalu buka Serial Monitor pada 9600 baud. Untuk Nano yang gagal upload setelah board dan port benar, coba opsi processor ATmega328P (Old Bootloader), sesuai bootloader unit.

Hasil yang diharapkan

Serial Monitor menampilkan “Board siap.” kemudian nomor yang terus bertambah. LED power saja belum membuktikan kabel USB mendukung upload.

05 / KODE

Salin, upload, lalu amati.

Contoh ini mengikuti wiring di atas. Cocokkan board dan library sebelum menekan Upload.

Kode uji utama Arduino / C++
unsigned long nomor = 0;

void setup() {
  Serial.begin(9600);
  Serial.println("Board siap.");
}

void loop() {
  Serial.print("Uji serial: ");
  Serial.println(++nomor);
  delay(1000);
}

Cara membaca kodenya

  • Tidak memerlukan sensor, LED tambahan, atau library pihak ketiga.
  • Nomor bertambah sekali per detik setelah upload berhasil.
  • Gunakan 9600 baud agar teks pada Serial Monitor terbaca.
06 / PERIKSA

Jika belum berhasil.

Mulai dari gejala yang paling dekat dengan hasil di meja.

Port tidak muncul+

Coba kabel USB data lain, port lain, dan periksa driver chip USB pada board.

Nano gagal upload+

Cocokkan board, port, dan pilihan processor/bootloader. CH340 sendiri tidak menentukan versi bootloader.

Teks menjadi karakter acak+

Samakan baud Serial Monitor dengan Serial.begin, yaitu 9600.

07 / LANJUTKAN

Setelah uji pertama berhasil.

Mulai dari satu sensor dan uji keluarannya. Tambahkan modul lain satu per satu agar sumber masalah mudah ditemukan.
