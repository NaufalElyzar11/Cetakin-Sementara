01 / KENALI

Sebelum mulai.

DHT22 membaca suhu dan kelembapan udara dengan resolusi yang lebih halus daripada DHT11. Pembacaannya tetap perlu diberi jeda, dan sensor perlu waktu untuk mengikuti kondisi lingkungan yang berubah. Cocok untuk memantau ruangan atau kotak proyek yang memiliki ventilasi.

Perhatikan bagian ini

Contoh memakai modul berlabel VCC/DATA/GND, bukan sensor telanjang empat kaki. Bila modul tidak memiliki resistor pull-up, pasang 10 kΩ antara DATA dan VCC. Urutan pin modul dapat berbeda.

04 / UJI

Coba satu langkah dulu.

  1. Cabut USB. Baca label pin dan hubungkan modul sesuai diagram; cek keberadaan pull-up DATA.

  2. Pasang kedua library melalui Library Manager Arduino IDE.

  3. Upload kode dengan tipe DHT22. Buka Serial Monitor pada 9600 baud.

  4. Biarkan sensor menyesuaikan suhu ruangan. Bandingkan pembacaan setelah beberapa menit dan hindari menyentuh sensor ketika mengambil data.

Hasil yang diharapkan

Serial Monitor menampilkan suhu dalam °C dan kelembapan relatif dalam %RH setiap dua detik. Perubahan kecil antarsampel wajar.

05 / KODE

Salin, upload, lalu amati.

Contoh ini mengikuti wiring di atas. Cocokkan board dan library sebelum menekan Upload.

Kode uji utama Arduino / C++
#include <DHT.h>

const byte DHT_PIN = 2;
DHT dht(DHT_PIN, DHT22);

void setup() {
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  delay(2000);
  float suhu = dht.readTemperature();
  float kelembapan = dht.readHumidity();
  if (isnan(suhu) || isnan(kelembapan)) {
    Serial.println("Pembacaan gagal. Periksa kabel dan tipe DHT.");
    return;
  }
  Serial.print(suhu, 1);
  Serial.print(" C | ");
  Serial.print(kelembapan, 1);
  Serial.println(" %RH");
}

Cara membaca kodenya

  • Serial Monitor: 9600 baud.
  • Objek dht menggunakan DHT22; tipe harus sesuai sensor fisik.
  • isnan mencegah hasil pembacaan gagal ditampilkan sebagai angka yang sah.
06 / PERIKSA

Jika belum berhasil.

Mulai dari gejala yang paling dekat dengan hasil di meja.

Pembacaan gagal berulang+

Periksa DATA, ground, pull-up, dan tipe DHT dalam kode. Coba kabel pendek.

Suhu lebih tinggi dari ruangan+

Jauhkan sensor dari regulator, prosesor, dan kotak tertutup yang panas.

Library tidak ditemukan+

Pasang library Adafruit melalui Library Manager, termasuk dependency yang diminta.

07 / LANJUTKAN

Setelah uji pertama berhasil.

Simpan rata-rata beberapa pembacaan untuk tampilan. Jika dipakai mengendalikan kipas, pisahkan batas nyala dan mati supaya kipas tidak berubah status terlalu sering.
