01 / KENALI

Sebelum mulai.

MQ-2 mempunyai elemen pemanas dan bahan semikonduktor yang bereaksi terhadap beberapa gas serta asap. Pembacaannya dipengaruhi suhu, kelembapan, pemanasan, dan kondisi lingkungan. Angka ADC saja belum bisa disebut konsentrasi gas dalam ppm.

Perhatikan bagian ini

Ini panduan eksperimen, bukan pengganti alarm gas tersertifikasi. Jangan membuka sumber gas atau menyalakan api untuk pengujian. Pemanas dapat menjadi panas; gunakan catu 5 V yang memadai, bukan pin GPIO.

04 / UJI

Coba satu langkah dulu.

  1. Hubungkan AO dan ground bersama dengan semua sumber daya mati. Pastikan catu modul 5 V teratur.

  2. Nyalakan modul di tempat berventilasi dan jauh dari bahan mudah terbakar. Jangan menyentuh elemen pemanas.

  3. Untuk sensor baru, ikuti proses conditioning produsen. Manual Winsen menyebut setidaknya 48 jam pada kondisi uji standar; ini bukan berarti pembacaan sudah terkalibrasi setelah beberapa menit.

  4. Upload kode dan amati baseline di udara bersih setelah stabil. Untuk uji awal, cukup memastikan pembacaan masuk akal dan tidak macet di batas ADC.

Hasil yang diharapkan

Pembacaan awal bisa bergerak selama pemanasan. Kode menampilkan ADC relatif, tanpa label ppm atau klaim kadar gas aman.

05 / KODE

Salin, upload, lalu amati.

Contoh ini mengikuti wiring di atas. Cocokkan board dan library sebelum menekan Upload.

Kode uji utama Arduino / C++
const byte SENSOR_PIN = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  long total = 0;
  for (byte i = 0; i < 10; i++) {
    total += analogRead(SENSOR_PIN);
    delay(5);
  }
  Serial.print("Nilai ADC: ");
  Serial.println(total / 10);
  delay(300);
}

Cara membaca kodenya

  • Serial Monitor: 9600 baud.
  • Nilai ADC Uno berada pada rentang 0–1023. Angka ini belum memiliki satuan fisik.
  • Sepuluh sampel dirata-ratakan untuk mengurangi perubahan kecil pada pembacaan.
06 / PERIKSA

Jika belum berhasil.

Mulai dari gejala yang paling dekat dengan hasil di meja.

Baseline terus berubah+

Periksa kestabilan catu, waktu conditioning, dan perubahan lingkungan. Jangan langsung menetapkan ambang alarm dari satu sampel.

Modul terasa panas+

Pemanas memang bekerja. Matikan jika kabel, konektor, atau board lain ikut panas, atau jika catu tidak sesuai.

Ingin angka ppm+

Diperlukan informasi beban, kalibrasi R0, gas acuan, dan kurva sensor yang sesuai. Rumus map ADC ke ppm tidak cukup.

07 / LANJUTKAN

Setelah uji pertama berhasil.

Pisahkan proyek edukasi dari sistem keselamatan. Untuk pemantauan, simpan baseline dan perubahan relatif; jangan menyatakan udara aman hanya karena pembacaan rendah.
