01 / KENALI

Sebelum mulai.

PIR membaca perubahan inframerah yang melewati area deteksinya. Gerakan orang di depan sensor biasanya memicu keluaran, tetapi orang yang diam tidak selalu terus terdeteksi. Gunakan untuk pemicu gerak, bukan untuk menghitung orang atau memastikan ruangan kosong.

Perhatikan bagian ini

Periksa label VCC/OUT/GND pada PCB, bukan posisi pin dari tampak depan. Setelah diberi daya, biarkan sensor stabil dahulu. Trimpot waktu dan sensitivitas serta jumper retrigger dapat berbeda antar-unit.

04 / UJI

Coba satu langkah dulu.

  1. Cabut USB dan sambungkan VCC, GND, serta OUT ke D2 berdasarkan label board.

  2. Upload kode. Nyalakan, lalu tunggu sekitar 30–60 detik tanpa bergerak di depan sensor.

  3. Berjalan melintas dari samping di depan lensa. Amati perubahan status.

  4. Atur waktu tahan dan sensitivitas sedikit demi sedikit. Pada mode retrigger, gerakan baru dapat memperpanjang status HIGH.

Hasil yang diharapkan

OUT naik menjadi 1 saat gerakan terdeteksi, kemudian kembali 0 setelah waktu tahan berakhir dan tidak ada pemicu baru.

05 / KODE

Salin, upload, lalu amati.

Contoh ini mengikuti wiring di atas. Cocokkan board dan library sebelum menekan Upload.

Kode uji utama Arduino / C++
const byte SENSOR_PIN = 2;

void setup() {
  Serial.begin(9600);
  pinMode(SENSOR_PIN, INPUT);
}

void loop() {
  Serial.print("Status OUT: ");
  Serial.println(digitalRead(SENSOR_PIN));
  delay(200);
}

Cara membaca kodenya

  • Serial Monitor: 9600 baud.
  • Umumnya HIGH menandakan gerak pada HC-SR501.
  • Lama status HIGH dipengaruhi trimpot waktu dan mode retrigger, bukan hanya delay pada kode.
06 / PERIKSA

Jika belum berhasil.

Mulai dari gejala yang paling dekat dengan hasil di meja.

Langsung aktif saat dinyalakan+

Tunggu stabilisasi awal sebelum menilai hasil.

Tidak cepat kembali ke 0+

Periksa trimpot waktu, mode retrigger, serta gerakan lain di area deteksi.

Sering terpicu tanpa orang+

Jauhkan dari aliran udara panas, sinar matahari langsung, dan sumber panas yang bergerak.

07 / LANJUTKAN

Setelah uji pertama berhasil.

Gunakan millis untuk waktu nyala lampu jika proyek perlu tetap membaca input lain. Jangan mengandalkan PIR sebagai bukti bahwa tidak ada orang ketika seseorang diam.
