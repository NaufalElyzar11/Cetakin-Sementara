01 / KENALI

Sebelum mulai.

OLED I²C hanya memerlukan dua jalur komunikasi selain catu dan ground. Sebelum memilih library, pastikan controller layar. Ukuran 0,96 inci dan warna biru/kuning tidak cukup untuk memastikan SSD1306; ada modul yang memakai controller berbeda.

Perhatikan bagian ini

Contoh utama khusus SSD1306 128×64 yang mendukung catu dan logika 5 V. Jika unit hanya mendukung 3,3 V, jangan hubungkan jalur I²C 5 V Uno langsung: gunakan level shifter. Controller SH1106 membutuhkan library yang sesuai.

04 / UJI

Coba satu langkah dulu.

  1. Periksa controller, tegangan, dan urutan label empat pin. Pasang kabel dengan USB dicabut.

  2. Jalankan kode pemindai I²C di bawah lebih dahulu. Catat alamat yang ditemukan pada Serial Monitor 9600 baud.

  3. Pasang library dan ganti OLED_ADDR dalam kode utama dengan alamat hasil pemindai. 0x3C hanya nilai awal yang umum.

  4. Upload kode utama. Jika alamat ditemukan tetapi teks tetap rusak atau tidak muncul, pastikan controller dan resolusi sesuai library.

Hasil yang diharapkan

Layar menampilkan “Cetakin” dan “OLED siap dipakai.”. Scanner harus menemukan alamat perangkat sebelum kode utama dinilai.

05 / KODE

Salin, upload, lalu amati.

Contoh ini mengikuti wiring di atas. Cocokkan board dan library sebelum menekan Upload.

Pemindai alamat I²C Arduino / C++
#include <Wire.h>

void setup() {
  Serial.begin(9600);
  Wire.begin();
  bool ditemukan = false;
  for (byte alamat = 1; alamat < 127; alamat++) {
    Wire.beginTransmission(alamat);
    if (Wire.endTransmission() == 0) {
      Serial.print("Alamat I2C: 0x");
      if (alamat < 16) Serial.print('0');
      Serial.println(alamat, HEX);
      ditemukan = true;
    }
  }
  if (!ditemukan) Serial.println("Tidak ada perangkat I2C.");
}

void loop() {}
Kode uji utama Arduino / C++
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

const byte OLED_ADDR = 0x3C; // Ganti dari hasil scanner.
Adafruit_SSD1306 layar(128, 64, &Wire, -1);

void setup() {
  Serial.begin(9600);
  if (!layar.begin(SSD1306_SWITCHCAPVCC, OLED_ADDR)) {
    Serial.println("Inisialisasi layar gagal.");
    while (true) delay(100);
  }
  layar.clearDisplay();
  layar.setTextSize(1);
  layar.setTextColor(SSD1306_WHITE);
  layar.setCursor(0, 12);
  layar.println("Cetakin");
  layar.println("OLED siap dipakai.");
  layar.display();
}

void loop() {}

Cara membaca kodenya

  • Serial Monitor: 9600 baud untuk scanner dan pesan kesalahan.
  • layar.display mengirim buffer gambar ke layar; tanpa pemanggilan ini, perubahan teks belum tampil.
  • Kode warna SSD1306_WHITE berarti piksel menyala, bukan mengganti warna fisik layar.
06 / PERIKSA

Jika belum berhasil.

Mulai dari gejala yang paling dekat dengan hasil di meja.

Scanner tidak menemukan perangkat+

Periksa SDA/SCL, polaritas, catu, dan sambungan. Pada Mega gunakan D20/D21, bukan A4/A5.

Alamat ditemukan, layar masih kosong+

Periksa controller, resolusi, dan alamat. begin yang berhasil tidak membuktikan controller fisik cocok.

Teks bergeser atau rusak+

Unit mungkin SH1106. Gunakan library SH110X dan contoh untuk resolusi unit, jangan hanya mengganti alamat.

07 / LANJUTKAN

Setelah uji pertama berhasil.

Gabungkan dengan satu sensor setelah layar teruji. Sisakan ruang memori pada Uno; buffer layar 128×64 sendiri memakai sekitar 1 KB RAM.
