01 / KENALI

Sebelum mulai.

Lima sensor pantulan membantu robot mengetahui posisi garis terhadap pusat rangkaian sensor. Uji seluruh kanal terlebih dahulu tanpa menyalakan motor. Dengan begitu, kesalahan arah sensor tidak tertukar dengan kesalahan kendali robot.

Perhatikan bagian ini

Ada variasi konektor dan label BFD-1000. Pastikan tegangan catu dari dokumentasi unit dan identifikasi lima output garis pada PCB. Diagram memakai penamaan logis S1–S5, bukan nomor urut konektor. Pin tambahan obstacle atau touch tidak dipakai.

04 / UJI

Coba satu langkah dulu.

  1. Identifikasi VCC, GND, dan lima output garis. Jika label atau catu belum jelas, jangan menebak; periksa dokumentasi atau tanyakan penjual.

  2. Hubungkan kanal ke D2–D6 sesuai diagram dengan USB masih dicabut. Tempatkan sensor menghadap permukaan lintasan.

  3. Upload kode. Geser isolasi hitam di bawah setiap kanal satu per satu.

  4. Catat pola hitam dan putih, serta urutan kanal dari kiri ke kanan dilihat dari arah depan robot. Sesuaikan jarak ke lantai sampai setiap kanal berubah dengan konsisten.

Hasil yang diharapkan

Kanal di atas isolasi hitam mempunyai status berbeda dari kanal di atas kertas putih. Saat garis digeser, posisi status berbeda ikut berpindah.

05 / KODE

Salin, upload, lalu amati.

Contoh ini mengikuti wiring di atas. Cocokkan board dan library sebelum menekan Upload.

Kode uji utama Arduino / C++
const byte kanal[] = {2, 3, 4, 5, 6};

void setup() {
  Serial.begin(9600);
  for (byte i = 0; i < 5; i++) pinMode(kanal[i], INPUT);
}

void loop() {
  for (byte i = 0; i < 5; i++) {
    Serial.print(digitalRead(kanal[i]));
    Serial.print(i == 4 ? '
' : ' ');
  }
  delay(150);
}

Cara membaca kodenya

  • Serial Monitor: 9600 baud.
  • Urutan keluaran mengikuti D2 hingga D6, bukan otomatis urutan kiri ke kanan.
  • Kode belum mengasumsikan hitam = 0; tentukan setelah pengujian.
06 / PERIKSA

Jika belum berhasil.

Mulai dari gejala yang paling dekat dengan hasil di meja.

Semua kanal sama+

Periksa tinggi sensor, kontras lintasan, catu, dan pemetaan konektor.

Robot nanti belok ke sisi yang salah+

Urutan kiri dan kanan mungkin terbalik. Uji lagi dari orientasi depan robot.

Satu kanal tidak merespons+

Tukar kabel input Arduino untuk membedakan masalah kabel dari kanal sensor.

07 / LANJUTKAN

Setelah uji pertama berhasil.

Setelah pola terbaca, beri bobot posisi pada kanal kiri hingga kanan. Mulai dengan kecepatan motor rendah, lalu tentukan perilaku khusus saat semua kanal kehilangan garis.
