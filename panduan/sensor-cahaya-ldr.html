Resistansi LDR berubah ketika cahaya yang diterimanya berubah. Modul menerjemahkannya menjadi sinyal listrik. Gunakan pembacaan ini untuk membandingkan kondisi terang dan gelap, bukan untuk langsung menampilkan nilai lux.

Beberapa modul LDR hanya memiliki DO. Kode dan diagram di sini memakai varian dengan AO. Jika hanya ada DO, baca dengan digitalRead dan atur ambangnya lewat trimpot seperti pada guide sensor halangan IR.

04 / UJI

Coba satu langkah dulu.

  1. Pastikan modul mempunyai AO dan mendukung 5 V. Dengan USB dicabut, sambungkan VCC, GND, dan AO.

  2. Upload kode dan buka Serial Monitor 9600 baud.

  3. Catat pembacaan di tempat terang. Tutup LDR dengan tangan tanpa menyentuh sambungan, lalu catat pembacaan gelap.

  4. Pilih batas di antara dua kondisi tersebut. Ulangi uji pada lokasi pemasangan, karena pencahayaan meja percobaan bisa berbeda.

Hasil yang diharapkan

Angka ADC berubah saat LDR ditutup. Arah perubahan bergantung pada rangkaian pembagi tegangan di modul.

05 / KODE

Salin, upload, lalu amati.

Contoh ini mengikuti wiring di atas. Cocokkan board dan library sebelum menekan Upload.

Kode uji utama Arduino / C++
const byte SENSOR_PIN = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  long total = 0;
  for (byte i = 0; i < 10; i++) {
    total += analogRead(SENSOR_PIN);
    delay(5);
  }
  Serial.print("Nilai ADC: ");
  Serial.println(total / 10);
  delay(300);
}

Cara membaca kodenya

  • Serial Monitor: 9600 baud.
  • Nilai ADC Uno berada pada rentang 0–1023. Angka ini belum memiliki satuan fisik.
  • Sepuluh sampel dirata-ratakan untuk mengurangi perubahan kecil pada pembacaan.
06 / PERIKSA

Jika belum berhasil.

Mulai dari gejala yang paling dekat dengan hasil di meja.

Angka hanya 0 atau 1023+

Pastikan input membaca AO. DO hanya menghasilkan dua status.

Lampu proyek berkedip dekat ambang+

Gunakan dua ambang berbeda untuk nyala dan mati, serta ratakan beberapa sampel.

Nilai berubah setelah dipasang+

Posisi, bayangan casing, dan arah cahaya memengaruhi sensor. Kalibrasi kembali setelah pemasangan.

07 / LANJUTKAN

Setelah uji pertama berhasil.

Tempatkan LDR agar tidak menerima cahaya dari lampu yang dikendalikannya. Jika lampu menyinari sensor, sistem dapat terus bergantian menyala dan mati.
