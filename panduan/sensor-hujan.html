01 / KENALI

Sebelum mulai.

Modul ini memakai pelat berjalur konduktif untuk mendeteksi air. Saat permukaan basah, hubungan listrik antarjalur berubah. Hasilnya cocok untuk membedakan kondisi kering dan basah; bukan untuk menghitung curah hujan dalam milimeter.

Perhatikan bagian ini

Yang boleh terkena air hanya pelat pendeteksi. Board pembanding, konektor, dan Arduino harus tetap kering. Contoh memakai varian yang memiliki AO dan mendukung 5 V; jika modul hanya punya DO, gunakan pembacaan digital.

04 / UJI

Coba satu langkah dulu.

  1. Sambungkan pelat ke board pembanding dengan kabel pasangannya. Pastikan USB belum terpasang.

  2. Hubungkan VCC, GND, dan AO sesuai diagram. DO tidak dipakai pada uji ini.

  3. Upload kode dan catat angka ketika pelat kering.

  4. Teteskan sedikit air pada pelat. Bandingkan angka sebelum dan sesudah basah, lalu lap dan keringkan setelah pengujian.

Hasil yang diharapkan

Pembacaan berubah saat air menyentuh jalur sensor. Arah perubahan dapat berbeda antar-modul, jadi catat hasil kering/basah milik modul sendiri.

05 / KODE

Salin, upload, lalu amati.

Contoh ini mengikuti wiring di atas. Cocokkan board dan library sebelum menekan Upload.

Kode uji utama Arduino / C++
const byte SENSOR_PIN = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  long total = 0;
  for (byte i = 0; i < 10; i++) {
    total += analogRead(SENSOR_PIN);
    delay(5);
  }
  Serial.print("Nilai ADC: ");
  Serial.println(total / 10);
  delay(300);
}

Cara membaca kodenya

  • Serial Monitor: 9600 baud.
  • Nilai ADC Uno berada pada rentang 0–1023. Angka ini belum memiliki satuan fisik.
  • Sepuluh sampel dirata-ratakan untuk mengurangi perubahan kecil pada pembacaan.
06 / PERIKSA

Jika belum berhasil.

Mulai dari gejala yang paling dekat dengan hasil di meja.

Angka tidak berubah+

Pastikan kabel pelat terpasang dan kabel pembacaan berasal dari AO, bukan DO.

DO selalu aktif+

Atur trimpot sambil membandingkan pelat kering dan basah. Trimpot biasanya mengatur ambang DO, bukan memperbaiki nilai AO.

Pelat makin sulit membaca+

Bersihkan sisa mineral dan keringkan. Jalur terbuka dapat mengalami korosi; hindari membiarkannya terus basah dan bertegangan.

07 / LANJUTKAN

Setelah uji pertama berhasil.

Buat ambang dari data kering dan basah, lalu tambahkan jeda beberapa detik sebelum menyatakan “hujan”. Percikan tunggal tidak selalu berarti hujan sedang berlangsung.
