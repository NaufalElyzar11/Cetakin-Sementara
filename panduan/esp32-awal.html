01 / KENALI

Sebelum mulai.

ESP32 pada katalog memakai keluarga WROOM klasik. Siapkan upload dan Serial Monitor dahulu sebelum menambahkan Wi-Fi atau sensor. Bentuk port USB-C tidak menentukan pilihan board maupun tegangan GPIO; identifikasi modul dan board yang terpasang.

3,3 V

Perhatikan bagian ini

GPIO ESP32 bekerja pada logika 3,3 V dan tidak boleh menerima 5 V langsung. Jangan menyalin wiring Uno tanpa memeriksa level sinyal. Hindari pin flash dan strapping untuk percobaan pertama; cocokkan pinout board.

04 / UJI

Coba satu langkah dulu.

  1. Lepas semua sambungan eksternal, lalu hubungkan board dengan kabel USB data.

  2. Tambahkan URL paket stable Espressif dan pasang paket esp32. Pilih board yang sesuai; untuk WROOM klasik generik, ESP32 Dev Module dapat menjadi pilihan bila dokumentasi board mengarah ke sana.

  3. Pilih port USB serial dan upload kode. Jika sistem belum mengenali CH340, periksa driver dari produsen chip.

  4. Buka Serial Monitor pada 115200 baud. Bila upload berhenti pada Connecting, coba tahan BOOT saat koneksi dimulai lalu lepas setelah penulisan berjalan; ikuti petunjuk board jika urutannya berbeda.

Hasil yang diharapkan

Teks uji muncul dan nomor bertambah setiap detik. Pesan boot sesaat setelah reset bisa muncul sebelum teks program.

05 / KODE

Salin, upload, lalu amati.

Contoh ini mengikuti wiring di atas. Cocokkan board dan library sebelum menekan Upload.

Kode uji utama Arduino / C++
unsigned long nomor = 0;

void setup() {
  Serial.begin(115200);
  delay(500);
  Serial.println("ESP32 siap.");
}

void loop() {
  Serial.print("Uji serial: ");
  Serial.println(++nomor);
  delay(1000);
}

Cara membaca kodenya

  • Tidak bergantung pada LED bawaan, karena pin LED bisa berbeda antar-development board.
  • Serial Monitor: 115200 baud.
  • Kode uji ini tidak menggunakan Wi-Fi atau kredensial jaringan.
06 / PERIKSA

Jika belum berhasil.

Mulai dari gejala yang paling dekat dengan hasil di meja.

Connecting tidak selesai+

Periksa board, port, kabel data, dan tombol BOOT sesuai dokumentasi unit. Coba kecepatan upload lebih rendah bila perlu.

Sensor Uno membuat ESP32 restart+

Matikan daya dan periksa level tegangan. Output 5 V harus diturunkan sebelum menuju GPIO ESP32.

Program jalan, tetapi LED tidak berkedip+

Uji ini memang lewat serial. LED bawaan tidak seragam pada board WROOM generik.

07 / LANJUTKAN

Setelah uji pertama berhasil.

Pilih satu sensor yang level keluarannya cocok dengan 3,3 V. Untuk sensor 5 V seperti HC-SR04, tambahkan pengubah level pada keluaran sebelum menghubungkan ke ESP32.
